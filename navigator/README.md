# AstroApex · Lunar Landing Site Navigator

NASA Space Apps Challenge 2026. A mission-planning tool that compares landing sites and dates at the
Moon's south pole: where the Sun (power) and the Earth (direct radio link) sit against the real local
horizon, how flat the ground is, how close the ice is, and whether the lander survives the dark.

Türkçe sürüm: [BENIOKU.md](BENIOKU.md)

## What it does

- **Two scenarios side by side**: site, start date and duration; visibility windows for Sun, Earth and both.
- **Suitability score (0–100)** from six parts: power, comms, darkness, landing light, terrain slope, ice access.
- **Real terrain**: a skyline and slope for any point south of 82°S, from NASA LOLA elevation data.
- **Ice traps**: NASA's map of permanently shadowed regions on the 3D map; distance to the nearest large trap.
- **Find candidate points**: scans the polar region, drops steep and shadowed ground, and scores the remaining samples using the same time step as the scenario cards.
- **NASA study regions**: compares sampled points around each region centre in the NASA Lunar Surface Data Book;
  the October 2024 Artemis III candidates are marked.
- **Rover route to ice**: searches a slope-weighted route to a qualifying shadow area under a 15° limit. A route requiring the relaxed 25° limit is explicitly marked.
- **Whole-Moon layers**: a coarse slope map of the entire Moon, relief and permanent shadow at both poles, and a whole-Moon scan.
- **Temperature map** and **comms map**: estimated surface temperature at any moment; Earth visibility of every scanned point.
- **Battery chart**, **ready-made scenarios**, a two-page **mission report (PDF)**, an **assistant** that runs new
  simulations to answer questions, and a **guided tour** (the `?` button).

The page opens in English; the TR button switches to Turkish.

## How to run

No install, no build step, no login. Any one of these:

| Way | What to do |
|---|---|
| Single file | Open `dist/AstroApex.html` in a browser. It works offline. |
| From the folder | Open `index.html`, or run `python server.py --open` (Python 3.8+). |

`python tools/build_single.py` rebuilds the single file.

## NASA data and sources

| Topic | Source |
|---|---|
| Sun and Earth positions | NASA NAIF SPICE (CSPICE N0067), JPL DE440, `IAU_MOON` frame, `LT+S`; a 2-hour table for 2024–2040 in `data/spice_table.js` |
| Independent cross-check | astronomy-engine (VSOP87 / ELP), compared live in the Resources tab |
| Elevation, skyline, slope | NASA LOLA `LDEM_75S_240M` (PDS Geosciences), reduced to 480 m cells; LOLA 80 m skylines (Barker et al. 2023) for three region centres |
| Permanently shadowed regions | NASA Goddard PGDA `LPSR_75S_120M_201608` (Mazarico et al. 2011) |
| Study-region centres | NASA Moon to Mars Lunar Surface Data Book, M2M-30044 (March 2025), Table A2.1-1 |
| Whole-Moon slope, north pole | NASA LOLA `LDEM_16` and `LDEM_75N_240M` (PDS Geosciences); NASA Goddard PGDA `LPSR_75N_120M_201608` |
| Map imagery | LRO WAC global mosaic, NASA Moon Trek |

## Limits

Score, propellant, battery and temperature figures are preliminary-design indicators, not a certified
analysis. Slope is measured over 480 m and cannot show boulders or small craters. Permanent shadow is where
ice can survive, not proof of ice. Region centres are reference points, not landing spots. Outside three region centres
the skyline comes from a 480 m grid that can miss narrow nearby ridges, so sunlight hours and scan scores can
be optimistic. The score rates the site and date. Recommendations additionally screen battery depletion, no Earth
visibility and known mean slopes above 15°, and explain when neither plan meets those checks. The temperature
map is a radiative-equilibrium model, not a Diviner measurement.

## Files

| File | Role |
|---|---|
| `index.html`, `styles.css` | Page and styling |
| `js/ephem.js` | Ephemeris: SPICE table with an astronomy-engine fallback |
| `js/app.js` | Simulation, power model, charts, 3D map and its layers |
| `js/polar.js`, `data/polar_data.js` | South-pole terrain engine and data: skyline, slope, shadow, rover route |
| `data/global_data.js` | Whole-Moon slope map and north-pole pack (map layers and the coarse scan) |
| `js/scout.js` | Best-point scan and NASA region scoring |
| `js/report.js` | Mission report and PDF |
| `js/assistant.js` | Analysis engine and chat panel |
| `js/fx.js` | Opening sequence, backdrop, guided tour |
| `js/i18n.js` | English and Turkish text, sites, regions |
| `tools/` | Scripts that build the data files and the single-file version |

## Development checks

From the repository root, install the locked development dependencies with `npm ci` and Chromium with
`npx playwright install chromium`. Install `pypdf==6.21.4` in the Python environment used for tests.
Run `npm run build`, then `npm test`. The root [README](../README.md) describes the optional local AI
session, native engine and both regression workflows.
